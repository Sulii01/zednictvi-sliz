# Zednictví Sliž – web

Statický web zednické firmy Zednictví Sliž (Marek Sliž, Bystřice u Třince) – [www.zedniktrinec.cz](https://www.zedniktrinec.cz).

- `*.html` – jednotlivé stránky
- `css/style.css` – vzhled
- `js/main.js` – menu, galerie (lightbox), poptávkový formulář
- `img/` – fotografie (`img/nahled/` náhledy do galerií)
- `rekonstrukce/`, `domy/`, `fasady/`, `dalsi/`, `o-nas/`, `kontakt/` – přesměrování ze starých adres (Webnode)

Web nepotřebuje žádný build – stačí otevřít `index.html` nebo nahrát soubory na libovolný hosting.
